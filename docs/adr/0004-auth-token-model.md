# ADR-0004：令牌模型——占位令牌默认，固定令牌可选收紧

- 状态：v3.4 已修订，参见 [升级说明](../UPGRADE-3.4.md)。占位模式要求非空令牌，诊断接口不再输出实时令牌。
- 关联：`EDGE_TOKEN` 配置；`docs/OFFICE-ONBOARDING.md`

## 背景

两台机器的 Office→网关认证做法不同：一台内嵌固定边缘令牌进旁加载清单（更安全，但换机/重装要重新生成清单），另一台用 `PROXY_MANAGED` 占位令牌（更简单，凭据全归 CC Switch）。网关本身只监听 127.0.0.1，暴露面极小。

## 决策

默认**占位令牌模式**：`EDGE_TOKEN` 未设置时，接受任意令牌（Office 里填 `PROXY_MANAGED` 或任何值均可），转发凭据由 CC Switch 托管，网关永远不接触真实上游密钥。需要收紧时（如多人共机）在 `.env` 设置 `EDGE_TOKEN=秘密值`，此后错误令牌一律 401。若 CC Switch 数据库里有实时网关令牌（claude-desktop 通道），该令牌也始终被接受。

## 被否掉的方案

- **默认强制固定令牌**：低门槛用户第一次安装就会卡在"令牌是什么"，而 loopback 监听已把风险限制在本机；
- **完全不做校验分支**：连可选项都不留，共机场景不安全。

## 后果

- 开箱即用（验收工具在占位模式下对 401 检查输出 NOTE 而非 FAIL）；
- 用户设置 `EDGE_TOKEN` 后自动获得 401 防护，验收工具会真实检查；
- 文档必须写清两种模式的区别与切换方法。
